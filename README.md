# 🎻 *WebViolin*

Real-time violin tuner built with React, TypeScript, and the Web Audio API.

The project focuses on accurate violin pitch detection, responsive tuning feedback, and a scalable frontend architecture using a feature-oriented structure.

---

## ✨ Features

- 🎻 **Real-time frequency detection**
- 🎼 **Violin note recognition**
- 🎯 **Cent deviation visualization**
- 🎚 **Adjustable A4 reference** (415–445 Hz)
- 📱 **Responsive layout** for desktop and mobile
- 🎤 **Microphone input** via Web Audio API
- ⚡ **Low-latency audio processing**
- 🧩 **Feature-based frontend architecture**

---

## 🛠 Tech Stack

### Core
- **Framework:** React
- **Language:** TypeScript
- **Build Tool:** Vite

### State Management & Data Fetching
- **Global State:** Zustand
- **Server State:** TanStack React Query

### Audio Processing
- Web Audio API
- Custom pitch detection algorithm

### UI & Animation
- **Styling:** TailwindCSS
- **Animations:** Framer Motion
- **Notifications:** Sonner
